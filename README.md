## `01` / PROFILE

I'm an IT enthusiast focused on understanding, building, and managing modern IT infrastructure.

My primary interests are Linux systems, enterprise networking, virtualization, and defensive security.

I enjoy exploring how systems work internally, building practical lab environments, troubleshooting complex issues, and documenting the engineering process.

> Technical knowledge should be demonstrated through working systems, reproducible labs, and clear documentation.

## `07` / ENGINEERING APPROACH

```text
Understand  →  Build  →  Test
     ↑                    ↓
Document   ←  Troubleshoot
```

- Understand underlying mechanisms, not just commands.
- Build practical environments and test real configurations.
- Troubleshoot systematically and document root causes.
- Prefer reproducible procedures and clear documentation.
- Learn by experimenting, validating, and improving.
